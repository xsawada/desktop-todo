# デスクトップToDoリスト

Python（tkinter）で作った、デスクトップに常に表示しておけるシンプルなToDoリストです。

## 主な機能

- タスクの追加（入力欄に書いてEnterキー、または「追加」ボタン）
- 期限の入力（右の欄に「10/31」などと入力。空欄なら期限なし）
- 期限が近い順に自動で並べ替え（期限なしは一番下）
- 期限切れは赤、今日が期限のものは橙で表示し、期限切れの件数も表示
- 登録したタスクの修正（行をダブルクリック、または選んで「編集」ボタン）。タスク名と期限を直せる
- タスクの完了・削除（一覧から選んでDeleteキー、または「完了（削除）」ボタン）
- 窓を常に最前面に表示（チェックボックスで切り替え）
- 閉じても内容が残るよう、タスクを `tasks.json` に自動保存

## 工夫した点

- **入力チェック**：空欄や長すぎるタスクは登録できないようにし、同じタスクがあるときは確認する
- **期限の入力チェック**：「10/31」「10-31」「10月31日」「2026/10/31」、全角数字など多少違う書き方も受け付ける。「2/30」のような存在しない日付はエラーを表示し、過ぎた日付は登録してよいか確認する。年を省略したときは、12月に「1/10」と入力すれば翌年と判断する
- **追加と修正で同じチェック**：入力チェックを1つの関数にまとめ、追加でも修正でも同じルールで確認する。修正では、期限を変えていなければ「過ぎています」の確認を出さず、自分自身は重複扱いしない
- **修正後も見失わない**：修正で期限が変わって並び順が動いても、修正したタスクを選んだ状態で表示する
- **古いデータとの互換性**：期限機能を付ける前に保存したタスクも「期限なし」として読み込める。期限の値が読めないタスクも消さずに「期限なし」にし、その件数を知らせる
- **保存データの保護**：一時ファイルに書いてから置き換えるので、保存の途中で止まってもデータが壊れない
- **壊れたファイルへの対応**：保存ファイルが読めないときは消さずに `.broken` として残し、空の状態で起動する。形式のおかしいデータは読み飛ばし、その件数を知らせる
- **見た目の調整**：文字の大きさや色をファイル冒頭の「見た目の設定」にまとめ、数字を変えるだけで調整できるようにした

## 動かし方

Python 3 がインストールされていれば、追加のインストールは不要です。

```
python todo.py
```

Windowsでは拡張子を `.pyw` に変えると、ダブルクリックで黒い画面を出さずに起動できます。
