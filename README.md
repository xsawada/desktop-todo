# デスクトップToDoリスト

Python（tkinter）で作った、デスクトップに常に表示しておけるシンプルなToDoリストです。

## 主な機能

- タスクの追加（入力欄に書いてEnterキー、または「追加」ボタン）
- タスクの完了・削除（一覧から選んでDeleteキー、または「完了（削除）」ボタン）
- 窓を常に最前面に表示（チェックボックスで切り替え）
- 閉じても内容が残るよう、タスクを `tasks.json` に自動保存

## 工夫した点

- **入力チェック**：空欄や長すぎるタスクは登録できないようにし、同じタスクがあるときは確認する
- **保存データの保護**：一時ファイルに書いてから置き換えるので、保存の途中で止まってもデータが壊れない
- **壊れたファイルへの対応**：保存ファイルが読めないときは消さずに `.broken` として残し、空の状態で起動する。形式のおかしいデータは読み飛ばし、その件数を知らせる
- **見た目の調整**：文字の大きさや色をファイル冒頭の「見た目の設定」にまとめ、数字を変えるだけで調整できるようにした

## 動かし方

Python 3 がインストールされていれば、追加のインストールは不要です。

```
python todo.py
```

Windowsでは拡張子を `.pyw` に変えると、ダブルクリックで黒い画面を出さずに起動できます。
